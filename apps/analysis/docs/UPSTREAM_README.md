# 방구석 천문학자 · SPHEREx 분석 작업실 (통합판)

한결의 SPHEREx 시공간 앱(`한결/SPHEREx_TIME_3D`)에 경보의 TrueBlink 분석작업실(`경보/trueblink`, 배포: stellarium-web-preview `/analysis/`)의 좋은 생각을 합친 버전입니다.
**SPHEREx 실제 영상과 3D 시공간 모형을 항상 나란히** 두고, 그 둘레에 임무·발견·분석 도구를 정리했습니다.

- 관측 영상은 NASA/IPAC IRSA SPHEREx(DR1·QR3)만 씁니다. Gaia·SIMBAD·문헌은 위치·운동 값에만 씁니다.
- 가짜 자료를 만들지 않습니다. 값이 없으면 없다고 표시합니다. 모의 자료는 `?mock=1`에서만 씁니다.
- 모든 값에 출처 배지: [SPHEREx 측정] [외부 카탈로그] [계산·모델]. 과장은 표시(동그라미·화살표·3D 선)에만, 항상 "과장됨 ×N" 배지와 함께.
- 소행성·AI 기능은 넣지 않았습니다.

## 실행

**Node 없이 바로 보기**: macOS는 `START_PREVIEW.command`, Windows는 `START_PREVIEW.cmd`(파이썬 3 필요)를 실행하면 `preview/`(검증한 빌드)가 http://localhost:8710 에서 열립니다. `index.html`을 파일로 직접 열면 관측 파일 로딩이 막힙니다.

개발 실행:

```sh
npm ci
npm run dev -- --port 5186        # http://localhost:5186/?target=barnard
```

임의 좌표·이름 검색은 `scripts/server.py`(파이썬, :8000)가 필요합니다. 개발 서버는 `/api`를 :8000으로 넘깁니다. 다섯 시험 대상은 서버 없이 바로 열립니다.

```sh
python3 -m venv .venv && .venv/bin/pip install numpy astropy astroquery pyvo reproject pillow requests
.venv/bin/python scripts/server.py
```

## 실시간 NASA 자료 (2026-11-15 추가)

경보의 TrueBlink가 자료를 불러오는 방식(`docs/ARCHITECTURE.md`, `src/core/catalogs`, `src/gl/SkyGlobe.ts`)을 읽고, 서버 없이 브라우저가 바로 받을 수 있는 것만 골라 붙였습니다.

| 기능 | 어디서 받나 | 서버 |
|---|---|---|
| **천구 지도** (상단 `천구 지도 (실시간)`) | IRSA SPHEREx 전천 HiPS 큐브 `spherex_allsky_cube`, 102색 PNG 타일 | 필요 없음 (IRSA가 CORS 허용) |
| **이름 찾기** | CDS Sesame (하버드 미러 우선). J2000 위치를 고유운동으로 오늘 위치로 옮김 | 필요 없음 |
| **Gaia 별 겹치기** (Blink의 `✦ Gaia 별`) | VizieR I/355/gaiadr3 (하버드·IDIA·CDS 미러 순서) → 관측 날짜로 고유운동 이동 | 필요 없음 |
| 고른 좌표의 SPHEREx 날짜별 영상 | IRSA SIA·IBE (`scripts/server.py`) | 필요 (IRSA SIA는 CORS 없음) |

- 천구: 끌어서 돌리기, 휠·버튼으로 확대(1.5°–100°), 파장 슬라이더(0.75–5.0 µm, 100채널), 좌표나 이름으로 이동, 클릭으로 좌표 고르기. 고른 곳이 대상 근처(0.3° 이내)면 그 분석을 열고, 아니면 검색 서버에 그 영역의 영상을 요청합니다. 전천 영상은 1년 평균이라 변화를 보여 주지 않습니다.
- Gaia: 원의 크기는 G 등급, G < 11.5만 숫자 표시. 받는 데 실패하면 그렇게 적고 아무것도 대신 그리지 않습니다. 모든 대상에서 Gaia 원이 SPHEREx 별 위에 겹쳐, 우리 격자 좌표 변환이 맞다는 확인도 됩니다.
- 영어 전환: 상단 `한국어 | EN`. 임무·발견·안내·Blink·3D·변광·분광 실험실까지 바뀌고, 주소(`?lang=en`)에 남습니다. 문서와 CSV 머리글은 그대로입니다.
- TrueBlink 코드 중 천구 엔진(SkyGlobe, HEALPix)과 네트워크 도우미는 그대로 가져왔습니다(`THIRD_PARTY_NOTICES.md`).

## 화면 구성

```
┌ 방구석 천문학자 │ 다섯 대상 │ 좌표·이름 검색 │ [탐험|연구] │ 링크 복사 ┐
├───────────────────────────────────────────────┬──────────────┤
│ 대상 이름 · 지금 날짜 · 관측 k/n               │ 전천 위치도   │
│ ┌ SPHEREx가 찍은 영상 ┐ ┌ 3D 시공간 모형 ┐     │ 임무 카드     │
│ │ Blink·A−B·필터      │ │ 같은 시각·시야  │     │ (탐험 모드)   │
│ │ 파장 눈금(D1–D6)    │ │ SPHEREx 시선    │     │ 무엇이 바뀌었나│
│ └─────────────────────┘ └────────────────┘     │ 안내 카드     │
│ 공통 시간 막대                                  │              │
│ (연구 모드) 변광 분석실 · 분광 실험실 · 위치 측정 · 자료 출처 │       │
└───────────────────────────────────────────────┴──────────────┘
```

- **탐험 모드**: 대상마다 임무 카드(이야기 → 무엇을 찾을까 → 따라 해 보기). 각 단계 버튼이 실제 화면 상태를 바꿉니다. 예: WISE 0855는 ① 전체 파장 깜빡이기 ② D6만 ③ 차가운 천체 필터 ④ SPHEREx 시선으로 겹쳐 보기.
- **연구 모드**: 공통 무대 아래에 분석 탭이 열립니다. 탭과 관측 번호는 주소(`?mode=research&tab=spectrum&visit=3`)에 남아 **링크 복사**로 같은 화면을 다시 엽니다.

## TrueBlink 분석작업실과 비교해 더하고 뺀 것

| 기능 | TrueBlink | 한결 앱(이전) | 통합판 |
|---|---|---|---|
| 영상 자료 | 브라우저가 S3 FITS를 직접 범위 읽기 + SIA 중계 서버 | 미리 만든 float32 프레임 + 좌표 검색 서버 | 한결 방식 유지: 서버 없이 즉시 열리고 3D와 같은 격자 |
| 같은 파장끼리 비교 | 관측마다 같은 채널로 프레임 생성 | 검출기 선택 메뉴 | **파장 눈금 선택기**: D1–D6를 실제 파장 폭대로 그리고, 이 관측에 없는 검출기는 점선 |
| 차가운 천체 필터 | 4.2–4.8 µm − 0.77 × 3.82–4.05 µm | 없음 | **추가**: D6 − k·D5, k = (4.12/4.71)² ≈ 0.77(레일리–진스), 조절 막대, 대상 위치의 D6 빛 잔존율 측정 |
| 3D | 프레임을 시간·파장으로 쌓은 스택 | 시공간 정육면체, SPHEREx 시선 일치, 영상 겹치기 | **한결 3D 유지(필수)**, 영상 옆에 항상 표시 |
| 탐험/연구 모드 | 있음 | 없음 | **추가** |
| 임무 카드 | 있음(단계가 보기 설정) | 없음 | **추가**: 단계가 검출기·차이·필터·3D 시선·분석 탭까지 움직임 |
| 발견 목록 | 후보 표현 | 대상 카드 수치 | **추가**: 고유운동 맞춤 vs 목록값, 같은 파장 밝기 변화, 흡수 띠 |
| 안내 카드 | 왜 TrueBlink? / 지금 보이는 건? | 없음 | **추가**: 선형 가변 필터 그림, 인공물 6가지 |
| 하늘 지도 | SPHEREx 전천 HiPS | 없음 | **실시간 천구 지도**(TrueBlink SkyGlobe, IRSA에서 직접) + 레일의 작은 전천 위치도 |
| 측광·스펙트럼·광도곡선 | 측정 탭 | 변광 분석실·분광 실험실 | 한결 실험실 유지(시간·파장 지도, 흑체 비교, 흡수 깊이) |
| 위치 측정 | 고유운동 맞춤 | 대상 카드 | **잔차 그래프 추가**(측정 − 예측, 동·북 방향) |
| 자료 출처 | 출처 탭, CSV/JSON | 배지·IRSA 링크 | **자료 출처 탭**: 컬렉션·검색 시각·관측 목록 CSV |
| 링크 공유 | URL 상태 | 대상만 | **추가**: 모드·탭·관측 |
| 소행성 탭·SkyBoT | 있음 | 없음 | 제외(프로젝트 방침) |
| 영어/한국어 | 둘 다 | 한국어 | **둘 다** (`?lang=en`) |
| Gaia 별 겹치기 | 있음 | 없음 | **추가**(VizieR 실시간, 관측 날짜로 이동, 켜고 끄기) |

한결 앱에서 정리한 것: 세 줄짜리 도구 막대 → 두 줄 + 파장 눈금, 범례·관측 상세 → 접기, 3D를 탭 뒤에 숨기던 구조 → 영상과 나란히, 하단 대상 카드 → 위치 측정 탭.

## 차가운 천체 필터 확인 (실제 SPHEREx 픽셀)

WISE 0855 넓은 영상 5개 관측에서 밝은 별 위치의 D6/D5 밝기 비 중앙값은 0.71–0.80으로 이론값 0.77과 맞았고, 필터 뒤 별 잔존율 중앙값은 −0.08–0.04였습니다(거의 지워짐). 반면 D6 노출이 적은 관측에는 우주선 흔적이 남습니다. 그래서 화면에 "한 장에만 찍힌 점도 남을 수 있다"는 한계를 함께 적습니다. 이것은 색에 따른 선택이지 천체 판별이 아닙니다.
