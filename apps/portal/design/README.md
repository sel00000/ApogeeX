# 홈 화면 Figma 파일

Figma 파일: https://www.figma.com/design/w4tQJ0eIJ384GcUz1uvAiB (모두를 위한 SPHEREx! — 홈 V2). 아래 SVG를 붙여 넣어 만든 파일입니다.

`home-figma.svg`는 V2 홈 화면(1440px 데스크톱, 첫 화면부터 소개·안내·맨 위로·푸터까지)입니다. 실제 화면의 위치와 크기를 그대로 재서 만들었습니다.

## Figma에서 여는 법
1. Figma에서 새 디자인 파일을 엽니다.
2. `home-figma.svg`를 캔버스로 끌어다 놓습니다. 메뉴의 File › Import로 열어도 됩니다.
3. 프레임 `홈-데스크톱-1440`이 생기고, 그 안의 레이어를 바로 고칠 수 있습니다.

## 레이어 구성
| 그룹 | 내용 |
| --- | --- |
| `배경-블랙홀` | 블랙홀 배경 한 장(이미지). 실제 앱에서는 움직이는 배경입니다. |
| `상단바` | 로고, 메뉴, 소개 |
| `히어로` | 제목, 설명, `버튼-관측시작`, `버튼-튜토리얼` |
| `카드-방구석 천문학자` · `카드-플라네타리움` · `카드-소행성·혜성` | 유리 카드, 아이콘, 글 |
| `히어로-하단` | 프로젝트 소개 안내, 움직임 멈추기 |
| `소개` | 프로젝트 소개, 숫자 네 개, `안내-1~4` |
| `맨위로-버튼` · `푸터` | |

- 글은 모두 텍스트 레이어라 문구를 바로 바꿀 수 있습니다.
- 한글은 Apple SD Gothic Neo로, 영문만 있는 글은 SF Pro Display로 지정했습니다.
- SF Pro가 없다는 표시가 나오면 Apple 개발자 사이트에서 SF Pro 글꼴을 설치하거나, 해당 레이어를 Apple SD Gothic Neo로 바꾸면 됩니다.

## Figma에서 손봐야 하는 두 가지
- **유리 효과:** SVG로는 Figma의 배경 흐림(Background blur)을 담을 수 없습니다. 실제 앱처럼 보이려면 `글래스-1~3`, `상단바-글래스`, `버튼배경-2` 레이어에 Effects › Background blur(20 안팎)를 직접 추가하세요.
- **제목 색:** Figma는 SVG 글자의 그라데이션을 가져오지 못해서, "SPHEREx!"는 글자마다 같은 흐름의 색을 따로 넣었습니다. 매끈한 그라데이션을 원하면 텍스트 레이어의 Fill을 Linear로 바꾸세요.

디자인을 고친 뒤에는 앱 코드(`index.html`, `styles.css`)에도 같은 값을 반영해야 화면이 바뀝니다.
